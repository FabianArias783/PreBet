# OddsIQ - Plataforma de Probabilidades Deportivas con IA

## Despliegue
1. Clona el repositorio
2. Instala dependencias con `npm install`
3. Copia `.env.example` a `.env` y añade tus API keys (RapidAPI y Anthropic/OpenAI)
4. Ejecuta localmente con `npm start` (requiere vercel cli)
5. Despliega en Vercel con `vercel --prod`
